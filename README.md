## Project Overview

This backend service handles employee attendance management, including check-in, check-out, and attendance history. It integrates with the frontend (hosted in a separate repo/branch) to provide a seamless user experience.

---

## Technology Stack

- Java 17  
- Spring Boot  
- Maven  
- JUnit & Mockito (for testing)  
- PostgreSQL / MySQL (or your chosen DB)  
- Git & GitHub for version control  
- GitHub Actions for CI/CD
